# DalamudPlugins

KanoNoUta 维护的 Dalamud 国服插件仓库。

## 仓库地址

在 Dalamud 设置的自定义插件仓库中添加：

```text
https://raw.githubusercontent.com/KanoNoUta/DalamudPlugins/main/pluginmaster.json
```
